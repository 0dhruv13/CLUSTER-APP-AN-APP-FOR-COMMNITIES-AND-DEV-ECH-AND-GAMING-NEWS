# CLUSTER-APP-AN-APP-FOR-COMMUNITIES-AND-DEV-TECH-AND-GAMING-NEWS
Cluster is a native Android app for devs and gamers. It aggregates tech news and connects communities via modern UI hubs. Built with Kotlin, Jetpack Compose, and MVVM. Features offline data caching with Room, async Coroutines, Retrofit REST APIs, and Firebase backend. The ultimate platform to track industry trends, share code, and network.

# Cluster 🚀

**Cluster** is a native Android app for developers and gamers, blending curated tech news from IGN with interactive community hubs.

## 🛠️ Tech Stack
- **Language/UI:** Java, XML
- **Backend:** Firebase (Auth/Chat)

## 🚀 Setup
1. Clone repo.
2. Add `google-services.json` to `app/`.
3. Run project in Android Studio.
